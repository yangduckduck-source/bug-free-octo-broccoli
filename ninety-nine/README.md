# 99

CPU와 1:1로 붙는 카드 게임. 합계를 99 넘기지 않고 오래 버티는 쪽이 이긴다.
판은 ZERO RUN과 같은 칩 속 세계다. 가운데 누산기(ACC) 레지스터에 합계가 7세그먼트 숫자로 굴러가고,
99에 가까울수록 붉게 달아오른다. 넘치는 순간 화면이 깨지며 OF(오버플로)가 뜬다.

## 규칙

- 카드 52장(조커 없음). 각자 3장을 쥐고 동전 던지기로 선을 정한다.
- 차례마다 손패에서 1장을 내 합계를 바꾸고, 더미에서 1장을 뽑는다.
- 99를 넘기는 카드밖에 없으면 그 사람이 진다. 단판 승부.

| 카드 | 효과 |
|---|---|
| A | +1 또는 +10 (낼 때 고른다) |
| 2·3, 5~8 | 숫자만큼 더한다 |
| 4 | 0 · 순서 뒤집기 (둘이 하면 순서가 그대로라 사실상 0) |
| 9 | 0 |
| 10 | −10 (0 밑으로는 안 내려간다) |
| J·Q | +10 |
| K | 합계를 바로 99로 |

- 더미가 바닥나면 낸 카드(맨 위 빼고)를 섞어 다시 쓴다.
- 내 카드 밑에는 냈을 때 될 합계가 미리 보이고, 넘치는 카드는 흐리게 막혀 있다.

## 전적과 연승

제목 아래 줄에 이번에 켠 뒤의 승·패, 승률, 연승 중이면 'N연승 중'(아니면 최고 연승 기록)이 뜬다. 게임을 껐다 켜면(새로고침 포함) 0승 0패로 새로 시작한다.
이기면 ZERO RUN의 0이 화면 가운데서 웃으며 튀어 오르고, 연승이면 '2연승!', '3연승!' 자막과 함께
연승이 길수록 높고 긴 팡파르가 울리고 불꽃이 많아진다. 최고 연승을 새로 쓰면 '최고 기록!'이 붙는다.
지면 연승이 끊기고, 2연승 이상에서 졌으면 'N연승에서 멈췄다'가 뜬다. 판 도중 '새 판'은 전적에 넣지 않는다.

## CPU

한 가지 실력(보통). 숫자 카드로 버틸 수 있으면 숫자 카드를 쓰고, 0·−10·99로 만드는 '살길' 카드(4·9·10·K)는 아껴 둔다.
합계를 높여 상대를 몰아붙이되, 자기에게 살길이 없으면 너무 올리지 않는다. 내 손패는 보지 않는다.

## 소리

카드 내는 소리, 합계가 굴러갈 때 삑삑, K는 솟구치는 소리, 10은 떨어지는 소리, 90 넘으면 경고음, 넘침은 깨지는 소리.
오른쪽 위 버튼으로 끈다. 휴대폰은 넘칠 때 진동(안드로이드).
