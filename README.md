# ZERO RUN

반도체 칩 속, 숫자 0이 1로 된 세상을 달린다. 원버튼 무한 러너.

- 기둥은 1, 빈틈은 0. 지나가는 지형이 그대로 이진수가 된다.
- 거리는 전송한 바이트, 속도는 클럭(GHz)으로 잰다.
- 버그에 닿거나 빈자리로 떨어지면 끝.

## 조작

스페이스 · ↑ · 클릭 · 터치. 길게 누르면 높이 뛴다.

- 착지 직전에 눌러도 땅에 닿는 순간 뛴다.
- 발판 끝을 살짝 지나쳐도 아주 잠깐은 뛸 수 있다.

## 소리

- 버그를 넘을 때마다 음이 한 칸씩 오른다. 연속으로 넘을수록 높아진다.
- 클럭 비트(베이스 + 하이햇)는 속도가 오를수록 빨라진다.
- 16바이트마다 짧은 팡파르, 오버클럭 진입 때 경보.
- 오른쪽 아래 버튼: 소리 켬 → 효과음만 → 소리 끔.

## 버그

| 이름 | 모습 |
|---|---|
| 바퀴벌레 | 버그 하면 떠오르는 그 벌레. 발판 위를 바삐 오간다 |
| 글리치 | 깨진 픽셀. 떨린다 |
| 루프 | 도는 화살표 고리. 커졌다 작아진다 |
| 누수 | 바닥에 번지는 웅덩이. 점점 넓어진다 |
| NULL | 1이 빠진 자리. 윤곽만 남은 구멍 |
