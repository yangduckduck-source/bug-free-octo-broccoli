# 소유네 반도체 게임

브라우저에서 바로 하는 작은 게임 모음. 게임마다 HTML 파일 하나로 돌고 외부 의존성이 없다.

| 게임 | 폴더 | 한 줄 |
|---|---|---|
| 99 | [`ninety-nine/`](ninety-nine/) | CPU와 1:1 카드 대결. 차례마다 카드를 내 합계를 올리고, 99를 넘기는 쪽이 진다 |
| 버그 잡기 | [`bugs/`](bugs/) | 칩 구멍에서 튀어나오는 무당벌레 버그를 30초 동안 톡톡 잡는다. 0은 누르면 감점 |
| 칩 쌓기 | [`hbm/`](hbm/) | 지나가는 메모리 칩을 눌러 쌓는 원버튼 탑 쌓기. 딱 맞추면 TSV가 빛나고, ZERO RUN의 0이 꼭대기에 탄다 |
| 야구왕 | [`homerun/`](homerun/) | 원버튼 타격. 타이밍으로 볼·스트라이크·안타·파울·홈런, 아웃 세 개면 끝 |
| 양맞고 | [`yangmatgo/`](yangmatgo/) | 컴퓨터와 1:1로 치는 고스톱. 어르신도 잘 보이게 큰 글씨·큰 패 |
| ZERO RUN | [`zero-run/`](zero-run/) | 반도체 속 0이 1의 세계를 건너는 원버튼 러너 |

GitHub Pages로 배포하면 맨 위 주소가 게임 목록, `…/yangmatgo/`·`…/zero-run/`이 각 게임이다.

## 새 게임 추가

1. 폴더 하나를 만들고 `index.html`을 넣는다.
2. 맨 위 `index.html`(게임 목록)에 타일을 하나 추가한다.
3. 이 표에 한 줄 추가한다.

## 공장 장부 (모든 게임 공통)

`common/fab.js` 하나를 모든 게임과 로비가 함께 쓴다(불러오는 주소에 `?v=번호`를 붙여 둔다 — 고칠 때마다 번호를 올려야 휴대폰이 예전 파일을 쓰지 않는다). 이 기기 브라우저에만 저장한다(사용자마다 따로).

- **웨이퍼**: 공통 재화. 게임 한 판으로는 조금만(보통 2~3장, 아주 잘하면 6~8장, 한 판 최대 10장) 쌓인다. 게임마다 난이도에 맞춰 맞췄다: 칩 쌓기 단수÷4, 버그 잡기 점수÷20, 야구왕 득점÷2+안타÷4+홈런, ZERO RUN 1+바이트÷25, 99 승 3·패 1. 웨이퍼는 출근 도장·오늘의 공정·업적으로 주로 모은다.
- **직급**: 누적 웨이퍼로 승진한다. 인턴 → 사원(300) → 대리(1,000) → 과장(2,500) → 책임(5,000) → 수석(10,000) → 팹장(20,000).
- **출근 도장**: 하루 처음 들어오면 웨이퍼. 이어서 오면 20→25→30→35→40→45→7일째 100.
- **오늘의 공정**: 날마다 서로 다른 게임에서 세 가지 미션(25~40장), 셋 다 끝내면 보너스 60.
- **업적 121개(공장 전체·게임별) · 명예의 전당**: 게임별 최고 기록과 업적, 직급 사다리.
- **상점**: 겉모습만 바꾼다(승패 영향 없음).
  - **코팅**(소모형): 정해진 판 수(15~20판)만큼 그 게임을 하면 닳아 없어진다. 250~600장.
  - **소장판**(영구형): 4,000~9,000장. 과장 이상 직급에서 열린다.
  - 좋은 꾸미기일수록 높은 직급에서 열린다. 꾸미기 38종. 게임마다 칸이 여러 개라 겹쳐 입힐 수 있다.
    - 칩 쌓기: 재질(단색·그라데이션)·회로 무늬·착지 효과
    - 야구왕: 전자 공·타자 머리(선글라스·땀받이 띠·헤드폰)·손(손목밴드·반짝이 장갑)·배트(웨이퍼·레이저)·홈런 불꽃 꼬리
    - 버그 잡기: 손맛·도구(뿅망치·납땜 인두·진공 흡입기)·야간 조명
    - ZERO RUN: 0의 빛·모자(후드·안전모·학사모·왕관)·꼬리(비트·무지개)
    - 99: 카드 뒷면(웨이퍼·회로 기판·금박)
- 판이 끝나면 화면 위에 결과 쪽지(받은 웨이퍼, 끝낸 공정, 새 업적, 승진, 다 닳은 코팅)가 잠깐 뜬다.
- 온라인 랭킹은 앱 출시 때 구글 플레이 게임즈·애플 게임센터로 붙인다.
