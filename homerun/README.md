# 홈런왕

포수 뒤에서 투수를 보는 원버튼 타격 게임. 80년대 야간 경기장, LED 전광판.

## 조작

스페이스 · 클릭 · 터치. 공이 홈플레이트에 닿는 순간에 맞춰 누른다. 공을 놓기 전에 누르면 무시한다.

**타임**: 왼쪽 아래 버튼(또는 Esc·P). 경기 시계가 통째로 멈추고, 계속하기·처음부터를 고른다.
다른 앱이나 탭으로 가면 저절로 타임이 걸린다.

## 모션

투수와 타자는 관절(엉덩이·어깨·팔꿈치·손·무릎·발)을 3차원 공간에 두고,
동작마다 자세를 정해 그 사이를 부드럽게 잇는다. 경기장과 같은 원근으로 그린다.

- 투수: 세트 → 다리 들기 → 내딛으며 팔 젖히기 → 머리 위로 던지기 → 숙이며 뒷다리 들림. 공은 그 손에서 나간다.
- 타자: 투수가 공을 놓으면 배트를 당겨 준비 → 누르면 허리·어깨가 돌며 배트가 수평으로 홈을 지나 → 앞 어깨 너머로 감긴다.

## 판정

누른 순간과 공이 홈에 닿는 순간의 차이로 정한다.

| 차이 | 결과 |
|---|---|
| ±18ms 이내 | 홈런 |
| ±30ms | 2루타 |
| ±44ms | 안타 |
| ±62ms | 빗맞은 뜬공·땅볼 아웃 |
| ±95ms | 파울 (2스트라이크에선 카운트 그대로) |
| 그 밖 | 헛스윙 |
| 안 침 | 존 안이면 스트라이크, 밖이면 볼 |

존 밖 공을 치면 결과가 한두 단계 나빠지고, 많이 빠진 공은 헛스윙이 된다.
볼넷·삼진·주자 진루·득점이 있고, 아웃 세 개면 경기 끝. 최고 득점을 저장한다.

## 난이도

공 12개마다 레벨이 오르고 구속이 빨라진다(122km/h → 최고 162km/h).

| 레벨 | 열리는 것 |
|---|---|
| 1 | 직구 · 와인드업 |
| 2 | 체인지업 |
| 3 | 커브 · 세트포지션 |
| 4 | 슬라이더 |
| 5 | 포크 · 퀵모션 |
| 6 | 너클 · 다리 들고 멈칫 |
| 7 | 사이드암 |
| 8 | 라이징 직구 |

휘는 공은 처음엔 다른 곳으로 가는 듯하다가 끝에서 꺾인다.

## 소리

배트 딱 소리·미트 퍽·관중 함성·홈런 오르간, 심판 목소리(스트라이크!·볼!·홈런! 등 짧은 낱말).
오른쪽 아래 버튼: 소리·목소리 → 효과음만 → 끔.
