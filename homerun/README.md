# 홈런왕

포수 뒤에서 투수를 보는 원버튼 타격 게임. 80년대 야간 경기장, LED 전광판.

## 조작

스페이스 · 클릭 · 터치. 공이 홈플레이트에 닿는 순간에 맞춰 누른다. 공을 놓기 전에 누르면 무시한다.

**타임**: 왼쪽 아래 버튼(또는 Esc·P). 경기 시계가 통째로 멈추고, 계속하기·처음부터를 고른다.
다른 앱이나 탭으로 가면 저절로 타임이 걸린다.

## 모션

투수와 타자는 관절(엉덩이·어깨·팔꿈치·손·무릎·발)을 3차원 공간에 두고,
동작마다 자세를 정해 그 사이를 부드럽게 잇는다. 경기장과 같은 원근으로 그린다.
몸 전체를 별도 층에 한 덩어리로 칠한 뒤 바깥 윤곽만 한 번 둘러, 관절마다 이음매가 보이지 않게 한다.
몸통·골반은 어깨·가슴·등·허리 점들을 감싸는 곡선, 팔다리는 굵기가 변하는 원통에 원통형 그러데이션(오른쪽 위 조명).
등번호는 등이 카메라를 향할 때만 등판 안에 잘라 넣는다.
골반이 어깨보다 먼저 도는 꼬임을 넣었다. 유니폼·스타킹·언더셔츠·헬멧·글러브·배팅 장갑·가늘어지는 배트.

- 투수: 세트 → 다리 들기 → 내딛으며 팔 젖히기 → 머리 위로 던지기 → 숙이며 뒷다리 들림. 공은 그 손에서 나간다.
- 타자: 투수가 공을 놓으면 배트를 당겨 준비 → 누르면 허리·어깨가 돌며 배트가 수평으로 홈을 지나 → 앞 어깨 너머로 감긴다.

## 판정

누른 순간과 공이 홈에 닿는 순간의 차이로 정한다.

| 차이 | 결과 |
|---|---|
| ±18ms 이내 | 홈런 |
| ±30ms | 2루타 |
| ±44ms | 안타 |
| ±62ms | 빗맞은 뜬공·땅볼 아웃 |
| ±95ms | 파울 (2스트라이크에선 카운트 그대로) |
| 그 밖 | 헛스윙 |
| 안 침 | 존 안이면 스트라이크, 밖이면 볼 |

존 밖 공을 치면 결과가 한두 단계 나빠지고, 많이 빠진 공은 헛스윙이 된다.
맞는 순간엔 소리와 함께 공만 날아가고, 판정은 공의 비행에 맞춰 나온다:
안타·2루타는 땅에 떨어질 때, 홈런은 펜스를 넘을 때, 파울은 파울 지역에 떨어지거나 뒤로 넘어간 뒤,
뜬공 아웃은 수비수가 잡을 때, 땅볼 아웃은 처리할 시간 뒤.
볼넷·삼진·주자 진루·득점이 있고, 아웃 세 개면 경기 끝. 최고 득점을 저장한다.

## 난이도

공 12개마다 레벨이 오르고 구속이 빨라진다(122km/h → 최고 162km/h).

| 레벨 | 열리는 것 |
|---|---|
| 1 | 직구 · 와인드업 |
| 2 | 체인지업 |
| 3 | 커브 · 세트포지션 |
| 4 | 슬라이더 |
| 5 | 포크 · 퀵모션 |
| 6 | 너클 · 다리 들고 멈칫 |
| 7 | 사이드암 |
| 8 | 라이징 직구 |

휘는 공은 처음엔 다른 곳으로 가는 듯하다가 끝에서 꺾인다.

## 손맛

맞는 순간 화면이 아주 잠깐 멈칫한 뒤(히트스톱) 흔들리며 살짝 당겨지고, 흰빛이 번쩍이며 충격 고리·불꽃과 함께 "깡!" 글자가 튀어오른다.
홈런일수록 세게, 빗맞으면("팅") 약하게. 휴대폰은 진동도 함께 온다(안드로이드는 진동, 아이폰은 iOS 18 이상에서 '톡' 햅틱).

## 소리

알루미늄 배트 '까아앙!' 소리(빗맞으면 '팅')·미트 퍽·관중 함성·홈런 오르간.
심판·장내 아나운서 목소리는 직접 녹음한 사람 목소리다(플레이볼·스트라이크·헛스윙·볼·볼넷·파울·안타·2루타·홈런·아웃·삼진 아웃·게임 셋 12가지).
녹음은 앞뒤 침묵을 자르고 저음을 받친 뒤 압축하고 구장 메아리를 입혀 mp3로 파일 안에 넣었다. 녹음을 못 트는 브라우저에서는 기기 음성(TTS)을 낮게 깔아 대신한다.
오른쪽 아래 버튼: 소리·목소리 → 효과음만 → 끔.
