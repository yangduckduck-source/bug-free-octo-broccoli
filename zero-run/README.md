# ZERO RUN

반도체 칩 속, 숫자 0이 1로 된 세상을 달린다. 원버튼 무한 러너.

- 기둥은 1, 빈틈은 0. 지나가는 지형이 그대로 이진수가 된다.
- 거리는 전송한 바이트, 속도는 클럭(GHz)으로 잰다.
- 버그에 닿거나 빈자리로 떨어지면 끝.

## 오프닝

처음 켤 때 한 번 나온다(약 25초, 누르면 언제든 건너뜀). 제목 화면 왼쪽 아래 **오프닝** 버튼으로 다시 볼 수 있다.

1. **POWER ON** — 화면을 눌러 전원을 켠다(휴대폰은 첫 터치 뒤에야 소리가 나기 때문).
2. **제목** — 커서처럼 깜박이던 0, 지직거리며 켜지는 ZERO RUN.
3. **짧은 영상** — 은빛 웨이퍼 한 장에서 칩 하나로 빨려 들어가면, 회로 위로 1의 기둥이 차례로 서고 빈칸에서 0이 눈을 뜬다. 글리치·무당벌레·누수·스택이 번지고 기둥 하나가 NULL로 빠진다.
4. **프롤로그** — 어두워진 회로 위로 초록 글자가 터미널처럼 한 자씩 찍히고, 줄이 차면 위로 밀려 올라간다.

> 시스템 시각 00:00:00. / 웨이퍼 한 장 위에 도시가 세워졌다. / 불이 켜진 자리는 1, 꺼진 자리는 0. /
> 세상은 1의 기둥으로 이어진 길이었고 / 0은 그 사이의 빈칸일 뿐이었다. // 어느 클럭, 빈칸 하나가 눈을 떴다. //
> 길 위로 버그가 번지고 있었다. / 글리치가 픽셀을 갉아먹고 / 누수가 바닥을 적시고 / 스택은 천장에서부터 무너져 내렸다. //
> 멈추면 덮어쓰인다. / 0은 달리기 시작했다. / 아무것도 아닌 것이, 끝까지 가 보기로 했다.

## 조작

스페이스 · ↑ · 클릭 · 터치. 길게 누르면 높이 뛴다.

- 착지 직전에 눌러도 땅에 닿는 순간 뛴다.
- 발판 끝을 살짝 지나쳐도 아주 잠깐은 뛸 수 있다.

## 소리

- 버그를 넘을 때마다 음이 한 칸씩 오른다. 연속으로 넘을수록 높아진다.
- 클럭 비트(베이스 + 하이햇)는 속도가 오를수록 빨라진다.
- 16바이트마다 짧은 팡파르, 오버클럭 진입 때 경보.
- 오른쪽 아래 버튼: 소리 켬 → 효과음만 → 소리 끔.

## 난이도

멀리 갈수록 세계가 불안정해진다.

| 거리 | 변화 |
|---|---|
| 100 B | **클럭 요동** — 터보(▲, 1.25~1.4배)와 스로틀(▼, 0.6~0.72배)이 불규칙하게 번갈아 온다. 0.8초 전에 경고음과 표시가 뜬다. 최고 속도도 조금 오르고, 버그가 한 발판에 3마리까지 붙는다 |
| 150 B | **비트 플립** — 호박색 띠를 두른 짧은 발판. 1.5초마다 깜박이다 0으로 뒤집힌다. 꺼져 있으면 통째로 뛰어넘을 수 있다 |
| 200 B | **스택 오버플로** — 천장에서 내려온 기둥. 그 밑에서 뛰면 부딪힌다 |
| 250 B | **커널 패닉** — 경보와 함께 화면이 붉게 숨 쉰다. 370 B까지 점점 몰아쳐: 최고 속도 600→760, 터보는 1.6배까지·스로틀은 0.52배까지, 요동은 더 잦고 경고는 0.5초로 짧아진다. 머리 높이에 **나는 무당벌레**가 떠 있어 뛰면 부딪힌다. 비트 플립·NULL·스택이 늘고 버그가 한 발판에 4마리까지 붙는다. 지형은 여전히 '이론상' 지나갈 수 있게만 만든다 |

## 버그

| 이름 | 모습 |
|---|---|
| 무당벌레 | 빨간 등딱지에 까만 점. 발판 위를 아장아장 오간다 |
| 나는 무당벌레 | 날개를 파닥이며 머리 높이에 떠 있다. 밑으로 지나가되 뛰면 안 된다 (250 B부터) |
| 글리치 | 깨진 픽셀. 떨린다 |
| 루프 | 도는 화살표 고리. 커졌다 작아진다 |
| 누수 | 바닥에 번지는 웅덩이. 점점 넓어진다 |
| NULL | 1이 빠진 자리. 윤곽만 남은 구멍 |
| 스택 오버플로 | 천장에서 쌓여 내려온 호출 프레임. 밑으로는 지나가되 뛰면 안 된다 |
