# 양국수 뽑기

비 오는 밤 포장마차에서 손님 주문대로 수타면을 뽑는 원버튼 게임.

## 조작

스페이스 · 클릭 · 터치 하나.

- **누르고 있으면** 두 손이 벌어지며 반죽이 늘어난다.
- **놓으면** 오른손이 넘어와 반으로 접고, 도마에 탕! 내리친다. 가닥이 두 배가 된다 (1 → 2 → 4 → 8 …).
- 너무 늘리면 가운데서 **툭** 끊어진다. 반죽을 새로 잡아야 하고 손님은 그만큼 더 기다린다.

## 손맛

- 끊어질 때가 가까우면 반죽 가운데가 잘록해지고 하얗게 질리며, 두 손이 파르르 떨린다. 밀가루가 흩날리고 반죽이 끼익 버티는 소리가 높아진다.
- 끊어지기 직전(한계의 90% 이상)에 놓으면 **쫄깃!**, 75% 이상이면 **좋아**, 그보다 덜 늘이면 **덜 늘였다**.
- 끊어지는 지점은 매번 조금씩 다르고, 가닥이 많아질수록 빨리 늘어난다.
- 내리칠 때 화면이 흔들리고 휴대폰이 진동한다(안드로이드).

## 장사

- 저녁 6시부터 새벽 2시까지(실제 90초) 손님이 한 명씩 앉는다.
- 주문표에 면 이름과 가닥 수, 접은 횟수 동그라미, 기다림 띠가 있다. 띠가 다 줄면 손님이 일어선다.

| 주문 | 가닥 | 값 |
|---|---|---|
| 굵은 면 | 4 | 5,000 |
| 우동 | 8 | 6,000 |
| 중면 | 16 | 7,000 |
| 소면 | 32 | 8,000 |
| 세면 | 64 | 9,000 |
| 실국수 | 128 | 11,000 |
| 용수염면 | 256 | 14,000 |

- 늦은 시간일수록 가는 면 주문이 많아진다.
- 값은 접을 때마다의 손맛 평균으로 60~100% 받고, 쫄깃 한 번에 300원, 빨리 내면 1,000원 팁이 붙는다.
- 영업이 끝나면 영수증으로 그릇 수, 쫄깃 횟수, 끊어 먹은 반죽, 오늘 매상을 보여 주고 최고 매상을 저장한다.

## 소리

빗소리, 냄비 끓는 소리, 반죽 버티는 소리, 탕 내리치는 소리, 휙 접는 소리, 첨벙, 후루룩, 동전. 모두 브라우저에서 합성한다.
휴대폰에서 소리가 끊기면 화면에 손이 닿을 때마다 다시 깨운다. 오른쪽 아래 버튼으로 끈다.
