# 버그 잡기

ZERO RUN의 기판 세계에서 하는 30초 두더지 잡기. 칩의 구멍(비아) 12개에서 무당벌레 버그가 쏙쏙 튀어나온다.

## 조작

화면을 톡 누른다. 손가락 여러 개로 동시에 눌러도 된다.

## 규칙

- 빨간 무당벌레 버그 +1, 드물게 나오는 황금 버그 +5.
- 가끔 ZERO RUN의 주인공 **0**이 고개를 내민다. 누르면 -3, 연속이 끊기고 화면이 붉어진다. 그냥 두면 들어간다.
- 1.2초 안에 계속 잡으면 연속. 5연속부터 점수 ×2, 10연속부터 ×3. 빈 구멍을 누르거나 버그를 놓치면 연속이 끊긴다.
- 뒤로 갈수록 버그가 자주, 짧게 나오고, 두 마리씩도 나온다. 10초쯤마다 버그 떼가 우르르.
- 마지막 5초는 시계가 깜박이며 똑딱인다.
- 끝나면 점수와 잡은 버그 수, 누른 0 수, 직급(인턴 → 주니어 → 선임 → 수석 엔지니어 → 버그 헌터)을 보여 주고 최고 점수를 저장한다.
