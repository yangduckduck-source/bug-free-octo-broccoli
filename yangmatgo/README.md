# 양맞고

컴퓨터와 1:1로 치는 고스톱(맞고). 80년대 안방, 국방색 담요 위에서 치던 화투를 화면으로 옮겼다.

## 잘 보이게

- 모든 패 왼쪽 위에 **월 숫자**, 아래에 **패 종류**(광·열끗·홍단·청단·초단·피·쌍피·고도리·국진)를 크게 적었다.
- 바닥에 짝이 있는 내 패는 노란 테두리로 위로 솟는다.
- 글씨 18px 이상, 버튼은 손가락으로 누르기 쉽게 크게.
- 동작 사이 간격을 넉넉히 두어 무슨 일이 일어났는지 따라갈 수 있다.

## 소리와 목소리

- 패를 내리치는 "착!"은 고음 딱 소리, 종이 몸통 소리, 담요 쿵 소리를 겹쳐 만든다. 패가 바닥에 닿는 순간에 맞춰 난다.
- 폭탄·흔들기·쪽·뻑·따닥·싹쓸이·고·스톱·피박·광박·나가리·승패 때 목소리가 나온다.
  기기에 내장된 한국어 음성을 높고 발랄하게 쓴다. 실제 목소리는 기기마다 다르다.
- 오른쪽 위 버튼: 소리·목소리 → 효과음만 → 소리 끔.

## 규칙

- 48장(보너스 패 없음). 한 사람 10장, 바닥 8장, 더미 20장.
- 7점부터 고·스톱.
- 광 3장 3점(비광 포함 2점), 4장 4점, 5장 15점 / 열끗·띠 5장부터 1점 / 피 10장부터 1점(쌍피는 2장)
- 고도리 5점, 홍단·청단·초단 각 3점. 국진(9월 열끗)은 열끗과 쌍피 중 유리한 쪽으로 계산.
- 쪽·따닥·싹쓸이·뻑 먹기: 상대 피 1장(자뻑은 2장)
- 흔들기·폭탄 ×2, 피박·광박·멍따·고박 ×2, 3고부터 ×2씩, 나가리 다음 판 ×2
- 한 손이나 바닥에 같은 달 네 장이 몰리면 다시 섞는다.
